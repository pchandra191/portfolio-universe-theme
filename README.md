# 🌌 Portfolio Universe Theme

An immersive, space-themed developer portfolio website built with modern web technologies. Designed with a sleek cosmic aesthetic, interactive components, and fully responsive layouts to showcase your projects, skills, and professional experience.

[![Portfolio Universe Theme Banner](https://images.unsplash.com/photo-1506703719100-a0f3a48c0f86?auto=format&fit=crop&w=1200&h=400&q=80)](https://portfolio-universe-five.vercel.app/)

## ✨ Features

- **Cosmic UI/UX:** Space-inspired theme featuring deep dark backgrounds, glowing accents, and smooth transitions.
- **Interactive Sections:** Dedicated components for showcasing projects, work experience, skills, and contact information.
- **Fully Responsive:** Optimized for seamless viewing across desktops, tablets, and mobile devices.
- **Modern Tooling:** Built with Vite and TypeScript for lightning-fast performance and type safety.

## 🛠️ Tech Stack

- **Frontend:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), [PostCSS](https://postcss.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Icons & Assets:** Lucide React / Custom SVGs
